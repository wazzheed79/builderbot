# Chuffed Quotes

Chuffed Quotes is a quoting app for builders, plumbers, electricians and other trades. The name and tagline live in `builderbot-app/lib/brand.mjs`.

## Mission

Create and send a professional quote in under two minutes.

## Features

- Customer management
- AI quote generation
- Professional PDF quotes
- Quote status tracking
- Mobile-first design
- Business profile management

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Google Gemini
- Stripe
- Vercel

## Target Users

- Builders
- Plumbers
- Electricians
- Roofers
- Landscapers

## Quote Workflow

Draft -> Sent -> Accepted -> Rejected -> Expired
