# BuilderBot

BuilderBot is an AI-powered quoting platform built for builders, plumbers, electricians and other trades.

## Mission

Create and send a professional quote in under two minutes.

## Features

- Customer management
- AI quote generation
- Professional PDF quotes
- Quote status tracking
- Mobile-first design
- Business profile management

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI
- Stripe
- Vercel

## Target Users

- Builders
- Plumbers
- Electricians
- Roofers
- Landscapers

## Quote Workflow

Draft -> Sent -> Accepted -> Rejected -> Expired
